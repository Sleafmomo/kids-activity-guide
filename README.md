# 儿童兴趣班选班指南 · 3-12岁

帮助孩子家长筛选兴趣班/特长班的公共工具：**199 个项目的结构化数据库 + 纯静态筛选网页**。

核心原则是**透明筛选，不做黑盒推荐**：输入孩子年龄和期望培养的能力，直接筛出适龄项目；每一条数据都标注信源与依据，官方红线优先于商家话术。

**线上使用**：https://sleafmomo.github.io/kids-activity-guide/

## 功能

- **四组结果**：✓ 现在适龄 / ○ 还没到年龄（含距适龄月数）/ – 窗口已过 / ✗ 不建议（负面警示独立组，无论几岁都显示）
- **筛选**：年龄滑杆（半岁步进）、9 类能力多选（主次加权排序）、资源热度四级、分类/政策状态/环境/形式/运动量/成本、在家即可开展、关键词搜索（含别名）
- **条目详情**：项目介绍、安全提示、官方鼓励依据（含政策原文逐字引述）、形式与成本、信源分级
- **独立链接**：每个项目有 `#id` 直达链接，转发即分享
- **12 篇分类"怎么挑"指南**：核心原则、选机构要点、红线、花费参考
- **时间轴视图**：未来 12 个月的报班规划（现在可做 / 窗口即将关闭 / 未来 3/6/12 个月分桶）
- 手机端适配（筛选区滚动自动收起）、无账号体系、数据本地计算、不收集任何信息

## 数据概览

- **199 个项目**，12 大类：球类 19 · 水上 13 · 冰上/雪上 7 · 体能/极限/新兴 18 · 搏击/对抗/射术 14 · 智力/思维/科技 33 · 音乐 31 · 舞蹈 7 · 戏剧/表演/语言 17 · 美术/手工 21 · 自然/营地/户外 12 · 生活技能 7
- **体育类以 2026 爱知名古屋亚运会 43 个大项为基准**（大项入表，小项进别名，如自由泳/蛙泳→游泳）；艺术类按音乐六家族 + 美术四门类盘点；科技类按编程AI/机器人/模型/科学观察/思维五条线
- **政策状态**：官方鼓励 57 · 正常 127 · 有红线 9 · 不推荐 3 · 伪科学 1 · 学龄前违规 2
- **12 份官方文件逐字引述**（教育部、体育总局、卫健委、中办国办文件及国标等），官方鼓励项 100% 挂接文件依据
- **30 条信源三级分级**：官方文件/国标（24）> 权威机构/严肃媒体/学术著作（27）> 行业惯例（148），年龄口径不冒充官方结论

## 数据模型

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 全局唯一，发布后永不改名（外部链接依赖） |
| `name` / `aliases` | string / string[] | 显示名与搜索别名 |
| `category` | string | 12 分类之一 |
| `summary` / `detail` | string | 一句话简介 / 项目介绍 |
| `age_start` / `age_stop` / `age_window` | number? | 建议起始年龄 / 适龄窗口止点 / 原文口径 |
| `abilities` | object | 培养能力标签（主 2 分 / 次 1 分，用于加权筛选） |
| `traits` | object | 环境（室内/户外）/ 形式（团队/个人）/ 运动量 / 成本 |
| `heat` | string | 资源热度：hot / warm / cool / rare |
| `policy` | string | encouraged / normal / caution / discouraged / banned_preschool / pseudoscience |
| `caution` | string? | 安全提示与红线说明 |
| `family_ok` | bool | 在家即可开展 |
| `source_refs` / `source_tier` | array/string | 引用信源与分级 |
| `official_support` | array | 挂接的官方文件（policies.json） |

数据文件在 `data/`：`activities.json`（主数据）、`sources.json`（信源）、`policies.json`（官方文件+引述）、`guides.json`（分类指南）、`details.json`（项目介绍）、`categories.json`、`abilities.json`、`age_verification.json`（年龄口径核验台账）。

## 网页使用与部署

- **本地使用**：直接双击打开 `web/index.html`（数据以内嵌脚本加载，file:// 下可用，离线可用）。
- **线上部署**：GitHub Pages，`.github/workflows/deploy-pages.yml` 自动发布 `web/` 目录；也可将 `web/` 上传任意静态托管，无需服务器。
- **数据更新流程**：修改数据 → 跑四脚本管线（`extract_from_html.py` → `validate.py` → `export_review_xlsx.py` → `build_web_data.py`）→ 校验通过后提交推送，线上自动更新。

## 数据维护规则

1. **信源分级铁律**：没有官方文件支持的年龄口径，`source_tier` 必须标 `industry`，不得伪装成官方结论；引述必须逐字可核对，取不到宁可留空。
2. **信源收录标准**：国家级以上机构（部委/总局/国标/国际权威机构）、严肃媒体（人民日报/光明日报/央广/央视/中新社等）、学术著作三类载体；渠道型信源不收录。
3. 政策类结论以官方最新发布为准，定期复核。
4. 新增项目先查重（aliases），避免同义重复条目。
5. 免责声明：本工具信息仅供参考，报班前请实地核实机构资质；政策类结论以官方最新发布为准。
