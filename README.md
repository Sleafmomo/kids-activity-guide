# 儿童兴趣班选班数据库（kids-activity-guide）

帮助 3–12 岁孩子的家长筛选兴趣班的公共工具。核心是**结构化、有信源、可持续维护的项目数据库**，前端只做透明筛选（输入年龄 + 期望培养的能力，输出适龄项目），不做黑盒推荐分析。

## 产品决策（已定稿）

| 决策项 | 结论 |
|---|---|
| 产品形态 | 纯静态网页 + 仓库内 JSON 数据文件起步，数据资产未来可复用到小程序 |
| 覆盖年龄 | 3–12 岁（学龄前到小学毕业） |
| 数据维护 | 本仓库数据文件，改动走版本记录 |
| 首批范围 | 全量项目先铺基础字段，官方鼓励文件等深度信息分批补 |
| 性别字段 | 仅用于极少数生理相关提示，**不**做"男孩推足球、女孩推舞蹈"式过滤 |
| 立场 | 继承自定制清单：男孩学芭蕾完全正常；官方红线优先于商家话术 |

## 网页使用与部署

- **本地使用**：直接双击打开 `web/index.html` 即可（数据以内嵌脚本形式加载，file:// 下也能工作，离线可用）。
- **本地预览服务**：`cd web && python3 -m http.server 8765`，访问 http://127.0.0.1:8765 。
- **线上站点（GitHub Pages，2026-10-31 上线）**：https://sleafmomo.github.io/kids-activity-guide/ —— 仓库 `Sleafmomo/kids-activity-guide`，`.github/workflows/deploy-pages.yml` 自动把 `web/` 发布到 Pages；`git push` 到 main 即自动更新线上（约 1 分钟）。
- **历史方案**：EdgeOne Pages 免费预览链接（*.zh-cn.edgeone.cool）对中国大陆加速区域仅 3 小时有效（401 过期机制），已弃用；其自定义域名需 ICP 备案。
- **数据更新流程**：改 `scripts/extract_from_html.py` 中的 E 字典（增/删/改条目）→ `python3 scripts/extract_from_html.py` → `python3 scripts/validate.py` → `python3 scripts/export_review_xlsx.py` → `python3 scripts/build_web_data.py` → git commit + push（线上自动更新）。

### 去个性化处理（已完成）

原定制清单的 146 条推荐理由（detail_original 字段）含有针对特定孩子的措辞。处理方式为**两层物理隔离**：①提取时即把个性化字段（detail_original/source_original/badge_original/verified_at/notes）从 activities.json 拆出，写入 `data/personal_archive.json`（已 gitignore，仅本地留存，公开仓库不含）；②`build_web_data.py` 生成网页数据时再剔除一遍并通过关键词断言自检（"孩子已4岁半""本城""他未表现"等不得出现在网页数据中）。网页端永不展示。

## 数据模型

### activities.json（主数据）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 稳定唯一 ID，如 `ball-basketball`，前端引用与外链均以此为准，永不改名 |
| `name` | string | 项目名 |
| `aliases` | string[] | 常见别名/机构叫法，用于搜索 |
| `category` | string | 大类 id（见 categories.json） |
| `summary` | string | 一句话简介：这是什么、练什么 |
| `age_start` | number \| null | 建议开始年龄（岁，支持 4.5 小数；null 表示"非课程类/按需"） |
| `age_window` | string | 适宜窗口描述，如 "4-8 岁为启蒙黄金期" |
| `age_stop` | number \| null | 窗口结束年龄（主要用于"已过窗口"判断，如平衡车 2-4 岁） |
| `abilities` | object | `{ "主标签": 2, "次标签": 1 }`，2=主要增强、1=次要，键取自 abilities.json |
| `traits` | object | `{ indoor: "indoor/outdoor/both", group: "team/solo/both", tempo: "active/calm/both", cost: "low/mid/high" }` |
| `heat` | string | 资源热度四级：`hot` 热门（全国普及）/ `warm` 常见（多数城市可找）/ `cool` 小众（一二线城市才有稳定供给）/ `rare` 稀缺（基本无稳定少儿培训体系） |
| `policy` | string | 见下方政策状态枚举 |
| `caution` | string \| null | 红线/安全/医学提示（有官方依据的写明依据） |
| `gender_note` | string \| null | 仅生理相关时填写，如舞蹈下腰、对抗类项目 |
| `source_refs` | string[] | 引用的信源 id（sources.json） |
| `source_tier` | string | 该条年龄口径的证据等级：`official`（官方文件）/ `authority`（权威机构）/ `industry`（行业惯例）——如实标注，不冒充 |
| `official_support` | string[] | 引用的官方文件 id（policies.json），空数组=暂无已核实文件 |
| `status` | string | `active` 正常收录 / `excluded` 仅展示（当前无此类条目） |
| `verified_at` | string | 数据核验日期 YYYY-MM-DD |
| `notes` | string \| null | 维护备注 |

### policies.json（官方文件表）

字段：`id`、`title`、`issuer`（发文机关）、`year`、`code`（文号）、`url`（官方直链，空=以文号检索为准）、`verified`（核实方式）、`gist`（与选班相关的要点）、`quote`（逐字原文引述，12/12 份均有——经官方页面或权威转载逐字核对，两份无官方直链的注明"据官方发布报道"）、`quote_src`（引述出处说明）。

现有 12 份（2026-10-31 核实）：体教融合意见（2020）、学校美育意见（2020）、劳动教育意见（2020）、义务教育课程方案 2022（教材〔2022〕2号）、科学教育意见（2023，教监管〔2023〕2号）、科技教育意见（2025，教基〔2025〕7号）、中小学 AI 教育通知（2024，教基厅函〔2024〕32号）、校园足球八大体系（2020）、冰雪运动进校园（2019）、青少年体育活动促进计划（2018）、近视防控实施方案（2018）、戏曲进校园实施意见（2017）。

**规则**：policy=encouraged 的条目必须有非空 official_support；policy=caution（年龄/安全红线）时红线优先，不升级为 encouraged，official_support 照常记录。

### abilities.json（能力词表，9 项）

| id | 名称 | 对应《3-6岁儿童学习与发展指南》领域 |
|---|---|---|
| `physical` | 体能协调 | 健康 |
| `resilience` | 勇气抗挫 | 健康·社会 |
| `focus` | 专注力 | 健康·科学 |
| `logic` | 逻辑思维 | 科学 |
| `creativity` | 创造力 | 艺术·科学 |
| `aesthetic` | 艺术审美 | 艺术 |
| `expression` | 语言表达 | 语言 |
| `social` | 社交协作 | 社会 |
| `hands_on` | 动手实践 | 科学 |

家长界面上展示通俗名称，底层映射到官方五大领域，使标签体系本身有出处。

### 政策状态枚举（policy）

| 值 | 含义 | 示例 |
|---|---|---|
| `encouraged` | 有官方文件明确鼓励（见 policies.json） | 游泳、足球、冰雪类、编程/机器人、劳动实践类、音乐美术舞蹈类（54 项） |
| `normal` | 正常项目，无特别政策 | 乒乓球、围棋 |
| `caution` | 可参与但有明确年龄/安全红线 | 蹦床（6 岁红线）、舞蹈（不下腰劈叉） |
| `discouraged` | 官方/权威机构不推荐 | 珠心算、感统训练（发育正常儿童） |
| `banned_preschool` | 学龄前违规办学（双减） | 学龄前英语班、幼小衔接学科班 |
| `pseudoscience` | 官方点名伪科学 | 全脑开发、量子速读 |
| `redline` | ⛔ 绝对禁止（预留等级，当前无独立条目——安全红线写在相关兴趣条目的 caution 内） | — |

### 筛选逻辑（前端，透明可解释）

输入：孩子年龄（岁，精确到 0.5）→ 期望能力（多选）→ 可选偏好（室内外、团队个人、成本）。

1. 年龄过滤：`age_start <= 年龄` 且（`age_stop` 为空或 `年龄 <= age_stop`）。未到年龄的项目不隐藏，归入"还有 N 个月适龄"分组——家长需要提前规划。
2. 能力匹配：主标签命中排序在前，次标签次之。
3. 政策状态以醒目标识展示（鼓励=绿、红线=黄、不推荐/违规/伪科学=红），**永不隐藏**——避坑信息和推荐信息同等重要。
4. 每条结果展示 `source_tier`：官方文件 / 权威机构 / 行业惯例，口径分级如实呈现。

## 数据维护规则

1. 所有修改通过数据文件（JSON）进行，每次修订写 `verified_at`，重要口径变化在 `notes` 记录。
2. **信源分级铁律**：没有官方文件支持的年龄口径，`source_tier` 必须写 `industry`，不得伪装成官方结论。
3. 政策类结论（双减、伪科学查处等）以官方最新发布为准，定期复核。
4. 新增项目先查重（aliases），避免"轮滑/旱冰"式重复条目。
5. **信源收录标准（v1.2.0 起）**：只收"国家级以上机构（部委/总局/国家级协会/国际权威机构）、严肃媒体（人民日报/光明日报/央广/央视/中新社等）、学术著作"三类载体；地方媒体、少年宫/培训机构等渠道型信源不收录。引述必须逐字可核对，取不到宁可留空，不编造出处（r18 器乐年龄即如实标注"行业通例"）。
6. 原始素材：`/Users/sleaf/WorkBuddy/2026-10-23-13-50-41/儿童兴趣班全景清单_权威修订版_副本.html`（私人定制版，2026-10-23 第 2 版，145 项、30 条信源）。
